# Modelo de Monografia - UESB

Este repositório contém um modelo de monografia desenvolvido para a **Universidade Estadual do Sudoeste da Bahia (UESB)**, com o objetivo de auxiliar estudantes na padronização e organização de seus trabalhos acadêmicos.
